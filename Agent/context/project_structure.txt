Project Structure Documentation
=============================

Directory Structure:
------------------
/
├── agent/                 # AI agent related code
├── assets/               # Game assets (images, sounds)
├── data/                 # Documentation and data files
├── game/                 # Core game logic
│   ├── game.py          # Main game loop and rendering
│   ├── game_state.py    # Game state management
│   └── state_manager.py # State management system
├── requirements.txt      # Python dependencies
└── README.md            # Project overview

Key Components:
-------------
1. Game Core (game/game.py)
   - Main game loop
   - Rendering functions
   - Collision detection
   - Camera system
   - HUD elements

2. Game State (game/game_state.py)
   - Player state management
   - Object management
   - Game configuration
   - Health system
   - Win/lose conditions

3. State Manager (game/state_manager.py)
   - State persistence
   - Command processing
   - External communication

4. Agent System (agent/)
   - AI decision making
   - Player interaction
   - Game analysis

Key Functions:
-------------
1. Rendering Functions:
   - draw_object(): Renders game objects
   - draw_player(): Renders player character
   - draw_minimap(): Renders minimap
   - draw_health_bar(): Renders health display
   - draw_fires(): Renders fire effects

2. Game Logic Functions:
   - check_collision(): Handles object collisions
   - update_player_position(): Updates player location
   - add_fire(): Spawns new fires
   - reset_game(): Resets game state

3. State Management:
   - save_state(): Saves current game state
   - get_new_commands(): Processes external commands
   - update_config(): Updates game configuration

4. Event Handling:
   - Process keyboard input
   - Handle game events
   - Manage game state transitions
