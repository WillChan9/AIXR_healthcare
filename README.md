## Firefighter Project

This repository contains a firefighter training/simulation environment built with Unity, together with supporting code in the `Agent` folder.

The Unity project lives in the `firefighter project` directory and can be opened directly from Unity Hub. The `Agent` folder is intended for additional tools or scripts (for example, controlling agents, training logic, data processing, or automation related to the simulation).

### Repository structure

- **`Agent/`**
  - Custom code, tools, or configuration used alongside the Unity firefighter environment.
  - The exact contents depend on your local setup (e.g. Python scripts, configuration files, or other utilities).

- **`firefighter project/`**
  - **`Assets/`**: All Unity game content: scenes, scripts, prefabs, models, animations, materials, etc.
  - **`Packages/`**: Unity packages (including any external dependencies referenced by the project).
  - **`ProjectSettings/`**: Unity project-level settings (input, graphics, quality, etc.).
  - **`.gitignore`**: Unity-specific ignore rules (e.g. for `Library/`, `Temp/`, build output, user-specific settings).
  - Other directories such as `Library/`, `Temp/`, `Obj/`, `Logs/`, `Build/` and `UserSettings/` are generated by Unity and are intentionally **not** tracked by Git.

- **Root (`s:\Firefighter_project`)**
  - `README.md` (this file).
  - Git repository root for both `Agent` and the Unity project.

### Prerequisites

🛠 **Prerequisites**

Before starting, ensure you have the following installed:

- **Unity Hub & Unity 6** (Recommended: 2022.3 LTS or newer).
- **Meta Quest Link App** (for PCVR testing).
- **Cursor IDE** (highly recommended for AI-assisted development).
- **Android Build Support** (installed via Unity Hub).
- **Optional – Agent tools**: If the `Agent` folder contains Python or other tooling, install the corresponding runtime and dependencies (for example, Python 3.x and a `requirements.txt`, if present).

### How to run the Unity firefighter project

1. **Open with Unity Hub**
   - Start Unity Hub.
   - Click **"Add"** and select the folder: `s:\Firefighter_project\firefighter project`.
   - Open the project with the recommended Unity version.

2. **Load a scene**
   - In the Unity Editor, open the `Project` window.
   - Navigate to `Assets/` and locate the main scene for the firefighter environment (for example, a scene file under `Assets/Scenes/`).
   - Double-click the scene to load it.

3. **Play in the Editor**
   - Press the **Play** button in the Unity toolbar to start the simulation.
   - Use any in-game controls defined by the project (e.g. keyboard/mouse) to interact with the environment.

4. **Build a standalone player (optional)**
   - Go to **File → Build Settings...** in Unity.
   - Add the main scene(s) to the **Scenes In Build** list.
   - Choose your target platform (e.g. Windows).
   - Click **Build** and choose an output folder (commonly `Build/` or `Builds/`).
   - Run the generated executable to launch the firefighter simulation without the Unity Editor.

### Working with the `Agent` folder

The `Agent` directory is a separate top-level folder under the Git root. It is intended for code or tools that work together with the Unity firefighter environment.

Typical patterns include:

- Scripts that control or communicate with agents in the Unity scene.
- Training scripts (for example, reinforcement learning workflows).
- Data processing or utility tools related to simulation runs.

Because the exact contents of `Agent` may change, please refer to any `README`, `requirements.txt`, or entry-point scripts inside `Agent` for detailed usage instructions. If no such documentation exists yet, you can document each tool there as you add it.

### Git workflow

- The Git repository root is `s:\Firefighter_project`, so **always run Git commands (e.g. `git status`, `git add`, `git commit`, `git push`) from this root directory**.
- The Unity `.gitignore` inside `firefighter project` ensures that large generated folders such as `Library/`, `Temp/`, `Obj/`, `Logs/`, `Build/`, and `UserSettings/` are not committed.
- Both `Agent` and `firefighter project` are tracked by the same repository, so a single commit can capture changes in both the Unity environment and the supporting agent code.
